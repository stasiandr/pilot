# Эталоны графа значения

`bin/graph-tests` читает отсюда файлы `*.txt` — или те, что переданы ему
аргументами. Строка:

```
/путь/к/Файл.cs:строка:столбец | Значение <- Код <- Источник | ещё цепочка…
```

Эталоны на конкретных проектах удобнее держать в самих проектах, рядом с
их расширением: `.pilot/extensions/<имя>/graph-tests.txt`.
